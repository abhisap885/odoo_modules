AI Connector & Assistant

Bring OpenAI, Anthropic, Google Gemini, Mistral & Ollama into Odoo

Overview

AI Connector & Assistant is a single, vendor-neutral module that lets you talk to the world's leading Large Language Models directly from your Odoo instance. Connect many providers, build reusable prompt templates with variables, run persistent chats and generate content without leaving Odoo.

Key Features

  • Multi-provider support: OpenAI, Anthropic Claude, Google Gemini, Mistral AI and local Ollama.
  • Centralised, encrypted API key storage per provider.
  • Reusable prompt templates with dynamic {{variables}}.
  • Persistent AI conversations with full history and token tracking.
  • "Ask AI" wizard available anywhere in the UI.
  • RAG over your products: index the catalog into embeddings and answer with retrieved, sourced context.
  • AI Live Chat auto-reply: the website live chat answers visitors using your product knowledge base — grounded, cited, multi-vendor.
  • Privacy-friendly: choose exactly what is sent to the model.
  • Multi-company ready.

Prompt Templates

Create reusable templates (summaries, reply emails, product descriptions, lead qualification, ...) with variables that are filled dynamically per record.

Configuration

  1. Install the module.
  2. Go to AI Connector > Configuration > Providers and create a provider.
  3. Enter your API key (encrypted at rest) and click Test Connection.
  4. Set a default provider under Settings > AI Connector.
  5. Open AI Assistant from the menu and start chatting.
