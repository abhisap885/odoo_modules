How the Workflow Works

STEP 1: INGESTION
Webhook or Cron Trigger
Shopify triggers an HMAC-verified webhook (Order, Product, Customer, Refund) or Odoo polls via scheduled cron or the manual Sync Wizard.
STEP 2: RESILIENCE
Lossless Staging Queue
Raw payloads land in shopify.feed in a Pending state. If tax or mapping rules are missing, inspect raw JSON and re-process with one click.
STEP 3: CONVERSION
Core Odoo Records
Feeds resolve to core Odoo records: Sales Orders, Deliveries, Partners, Products, and Invoices with automatic tax, discount, and carrier mapping.
STEP 4: FEEDBACK
Fulfillment & Stock Push
Validating delivery pickings in Odoo dispatches carrier tracking numbers to Shopify, marking orders fulfilled and updating live stock counts.

OFFICIAL USER GUIDE

Setup, Configuration & User Manual

1

Generate Shopify Admin API Credentials

To establish a direct connection between Shopify and your Odoo 19 instance without middleware, create a Custom App inside your Shopify Store Admin:

  1. Log in to your Shopify Store Admin and navigate to Settings → Apps and sales channels → Develop apps.
  2. Click Create an app and give it a name (e.g., Odoo 19 Shopify Connector).
  3. Under Configuration → Admin API integration, enable the following Admin API Access Scopes:
    read_products, write_products, read_orders, write_orders, read_customers, write_customers, read_inventory, write_inventory, read_locations, read_fulfillments, write_fulfillments, read_merchant_managed_fulfillment_orders, write_merchant_managed_fulfillment_orders
  4. Click Save and then click Install app.
  5. Copy your Admin API access token (starts with shpat_). Note: Store it securely as it is displayed only once.
2

Configure Shopify Store Instance in Odoo 19

With your API credentials ready, create a new connected store instance in Odoo:

  1. Open Shopify → Configuration → Stores in Odoo 19 and click New.
  2. Enter a store name (e.g. My Brand US) and your Shopify domain URL (e.g. mybrand.myshopify.com).
  3. Under the Credentials tab:
    • Select Authentication Mode: Admin API Token.
    • Paste your shpat_... token into the Admin API Access Token field.
  4. Under the Defaults tab, select your default Warehouse, Pricelist, Sales Team, Company, and Delivery Product.
  5. Click the Test Connection button in the top action bar. Upon successful verification, the store status changes to Connected.
3

Discover & Map Fulfillment Locations (Multi-Location Inventory)

Shopify stores can fulfill orders from multiple locations (e.g., Primary Warehouse, East Coast 3PL, Retail Store). Pair them with corresponding Odoo warehouses:

  1. On the Store Instance form, click the Discover Locations button.
  2. The connector automatically imports all active locations from Shopify into Shopify → Configuration → Location Mappings.
  3. For each discovered Shopify location, select the target Odoo Warehouse and Stock Location (e.g. WH/Stock).
  4. When orders are imported from Shopify, Odoo routes delivery pickings directly to the mapped warehouse. Stock export routines also push on-hand counts from the matching stock location to the respective Shopify location.
4

Configure Real-Time Webhooks with HMAC-SHA256

Enable real-time event updates from Shopify into Odoo (sub-second order creation):

  1. Copy your Webhook Secret Key from your Shopify Custom App overview.
  2. Paste it into the Webhook Secret field on your Odoo Store Instance form.
  3. In Shopify Admin, navigate to Settings → Notifications → Webhooks and create webhooks for:
    • orders/create → https://your-odoo-domain.com/shopify/webhook/orders_create
    • orders/updated → https://your-odoo-domain.com/shopify/webhook/orders_updated
    • refunds/create → https://your-odoo-domain.com/shopify/webhook/refunds_create
    • products/create & products/update → https://your-odoo-domain.com/shopify/webhook/products_...
  4. Every incoming webhook is verified cryptographically via X-Shopify-Hmac-Sha256 headers before being accepted into the lossless queue.
5

Declarative Metafields Mapping Engine

Map arbitrary Shopify custom fields directly to Odoo model attributes without writing Python code:

  • Navigate to Shopify → Configuration → Metafield Mappings.
  • Select the target entity (product.template, product.product, res.partner, sale.order).
  • Specify the Shopify Metafield Namespace (e.g. custom) and Key (e.g. material_care).
  • Select the matching Odoo Field from the dropdown.
  • Set the Direction: Bidirectional, Import Only, or Export Only. Supported types include Single-Line Text, Multi-Line Text, Integer, Decimal, Boolean, JSON, and URL.
6

Automated Order Refunds & Credit Notes

When customer returns or refund adjustments occur on Shopify:

  • Shopify triggers a refunds/create event or the Sync Wizard fetches recent refunds.
  • The connector locates the matching Odoo Sales Order and its posted customer invoice.
  • Automatically generates a Customer Credit Note (account.move of type out_refund) with the exact refund amount and line item breakdowns.
  • Configure optional automation toggles on your Store form: Auto-Process Refunds, Auto-Create Credit Notes, and Auto-Post Credit Notes.

Frequently Asked Questions (FAQ)

Can I connect multiple Shopify stores with different currencies?

Yes. Each Shopify store instance is independent. You can assign different default currencies, pricelists, warehouses, sales teams, and Odoo companies to each store.

Are there recurring monthly subscription or middleware fees?

No. Unlike connector SaaS platforms that charge per order or per month, this module is a one-time purchase with direct Odoo-to-Shopify GraphQL communication and zero intermediary fees.

Does this module support Odoo.sh cloud hosting?

Yes. The module is fully tested and 100% compliant with Odoo.sh, standard on-premise servers, and containerized Docker environments without any custom OS dependencies.

What happens if an order contains an unmapped product?

The raw order lands safely in the shopify.feed queue with an error flag. No data is lost. You can either auto-create the missing product or manually map it, then click "Process" to convert the order immediately.
