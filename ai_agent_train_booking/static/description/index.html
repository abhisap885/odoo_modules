Agentic AI Autonomous Train Ticket Booking

Autonomous tool-calling AI agent for end-to-end train reservations, PNR lifecycle, seat allocation, and live operations in Odoo 19.

Key Capabilities

  • Agentic Reasoning Loop: Breaks down natural language requests into structured tool executions (Search → Check Seats → Reserve → Allocate Berth → Confirm).
  • 6 Pre-Registered Tools: search_trains, check_seat_availability, book_train_ticket, confirm_ticket, get_pnr_status, cancel_ticket.
  • Zero-Dependency Out-of-the-Box Operation: Includes a deterministic autonomous engine so you can test and demonstrate full booking flows immediately without an API key.
  • External LLM Support: Connects directly to OpenAI (GPT-4o), Google Gemini, Anthropic Claude, or local Ollama.
  • Human-in-the-Loop Autonomy: Toggle between fully autonomous booking and supervised approval mode.
  • Full Audit Trace: Inspect each step's Thought, Tool Call, Arguments, and Odoo ORM Result.

Quick Start

  1. Navigate to Train AI Agent → AI Agent → Quick Agent Console.
  2. Select a sample preset or enter a prompt: "Book a ticket from New Delhi to Mumbai tomorrow for Amit Sharma in 2AC".
  3. Click Run AI Agent to witness autonomous tool execution, seat allocation, and instant PNR generation!
